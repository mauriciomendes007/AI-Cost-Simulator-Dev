📡 API Documentation

Use the AI Cost Simulator API to integrate cost calculations into your AI applications, bots, and automation tools.

Base URL

https://ai-cost-simulator.com/api

Calculate Cost - POST /calculate

Calculate the cost for a given model and token count.

Request Body:

{ "modelId": "openai/gpt-4", "inputTokens": 500000, "outputTokens": 100000, "currency": "USD" }

Response:

{ "success": true, "data": { "inputCost": 0.075, "outputCost": 0.03, "totalCost": 0.105, "currency": "USD", "model": { "id": "openai/gpt-4", "name": "OpenAI GPT-4", "inputPrice": 0.00015, "outputPrice": 0.0003 }, "timestamp": "2026-09-12T08:45:00Z" } }

Get Models - GET /models

Retrieve all available models with their pricing information.

Response:

{ "success": true, "data": [ { "id": "openai/gpt-4", "name": "OpenAI GPT-4", "inputPrice": 0.00015, "outputPrice": 0.0003, "provider": "openai" }, ... ] }

JavaScript Example

const response = await fetch('https://api.ai-cost-simulator.com/calculate', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ modelId: 'openai/gpt-4', inputTokens: 500000, outputTokens: 100000, currency: 'USD' }) }); const data = await response.json(); console.log(`Cost: ${data.data.currency}${data.data.totalCost}`);

Python Example

import requests response = requests.post( 'https://api.ai-cost-simulator.com/calculate', json={ 'modelId': 'openai/gpt-4', 'inputTokens': 500000, 'outputTokens': 100000, 'currency': 'USD' } ) data = response.json() print(f"Cost: {data['data']['currency']}{data['data']['totalCost']}")

cURL Example

curl -X POST https://ai-cost-simulator.com/api/calculate \ -H "Content-Type: application/json" \ -d '{ "modelId": "openai/gpt-4", "inputTokens": 500000, "outputTokens": 100000, "currency": "USD" }'
